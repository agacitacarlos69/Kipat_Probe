# Essential Mono

> **Nothing but Kipat and the point: typography and restraint.**

| | |
|---|---|
| Character | Timeless, confident, minimal. |
| Tone | Light (white / graphite), with a dark variant (soft black / soft white) |
| Material | Matte laminated white-core PVC; dark variant has a soft-black flood. |
| Finish | None. That is the point. |
| Inks | One ink plus the base (graphite on white; soft white on soft black). |
| Production complexity | LOW: the cheapest and most reliable edition. |
| Reveal pairing | Minimal Fade (recommended, not locked). |

## Front wireframe (before art)

```
┌──────────────────────────────────────────────┐        ┌──────────────────────────────────────────────┐
│ (•)) kipat                                   │        │ (•)) kipat                                   │
│                                              │        │                                              │
│                                    ●         │        │                                    ●         │
│                                              │        │                                              │
│                                              │        │ VP                                           │  monogram (personalised)
└──────────────────────────────────────────────┘        └──────────────────────────────────────────────┘
          generic (inventory)                                     personalised
```

| Element | Why it exists |
|---|---|
| Lockup | The only branding. |
| Contact point in the edition ink (no cobalt) | Mono means one ink; the point stays the tap cue. At 2.4 mm on the grid it reads as deliberate, not as a speck (verify on the printed proof). |
| Optional monogram, Inter Medium 22 pt, bottom-left | Ownership without putting a full name on the front; sits on the margin grid opposite the lockup. |

Nothing else is on the front.

## Back (shared Kipat architecture)

```
┌──────────────────────────────────────────────┐
│ Vash Puno                                    │  name: who this card belongs to
│ BS Computer Science                          │  context: why you'd remember them
│ Polytechnic University of the Philippines    │
│                                     ┌──────┐ │
│                                     │  QR  │ │  fallback for phones without NFC/Kipat (optional)
│ (•)) Tap to connect                 └──────┘ │  the one instruction; the mark is the tap cue
└──────────────────────────────────────────────┘
```

Identical on every edition, so any Kipat card is recognisable from the back. The generic inventory
back replaces the name block with the lockup and prints no QR (`back-generic.svg`).

## Critique

- *Risk: too empty, or the dot reads as a print defect.* It must be printed at full size and checked; if
  the dot reads as a speck, the fix is the monogram edition, not adding decoration.
- Most timeless, cheapest and most reliable. A likely best-seller in white.

## Files

- `front.svg`, `back.svg`, `back-generic.svg`: vector masters (outlined Inter, hidden plates and guides)
- `front-proof.png`, `back-proof.png`, `back-generic-proof.png`: flat proofs (no finish simulation)
- `front-finish.png`: finish plates over the art (magenta = gloss, cyan = deboss)
- `front-guides.png`: grid, safe zone and NFC safety zone
Personalised front: `front-monogram.svg` / `front-monogram-proof.png`.

Dark variant: `front-dark.svg`, `back-dark.svg`, `back-generic-dark.svg`, `front-monogram-dark.svg` and proofs.

All artwork is generated by `design/card/tools/build.py`; edit it there, never by hand in the SVG.
