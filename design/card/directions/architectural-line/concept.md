# Architectural Line

> **One line enters from the edge, turns once, and ends at the contact point.**

| | |
|---|---|
| Character | Structured, precise, editorial, designed. |
| Tone | Light |
| Material | Matte laminated white-core PVC with a warm-neutral paper flood. |
| Finish | Raised spot gloss on the line only (stops at the 4 mm safe zone; the printed line continues into the bleed). |
| Inks | Paper flood, graphite, cobalt. |
| Production complexity | LOW–MEDIUM: standard PVC plus matte; optional raised gloss. |
| Reveal pairing | Line Assembly (recommended, not locked). |

## Front wireframe (before art)

```
┌──────────────────────────────────────────────┐
│ (•)) kipat                                   │  lockup
│                                              │
│                                    ●         │  contact point: where the line arrives
│                                    │         │  vertical: the one turn
│                                    │         │
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛         │  line enters from the left edge (y 41 mm)
└──────────────────────────────────────────────┘
```

| Element | Why it exists |
|---|---|
| Line, 0.5 mm graphite | The single idea: a drafted path leading to the point of contact. It bleeds off the left edge, so it belongs to something larger than the card. |
| One right-angle turn | Architecture, not a circuit: one decision, no branching, no nodes, no pads. |
| Contact point at the end | The line has a destination: you. |
| Lockup | Same position as every edition. |

Nothing else is on the front.

## Back (shared Kipat architecture)

```
┌──────────────────────────────────────────────┐
│ Vash Puno                                    │  name: who this card belongs to
│ BS Computer Science                          │  context: why you'd remember them
│ Polytechnic University of the Philippines    │
│                                     ┌──────┐ │
│                                     │  QR  │ │  fallback for phones without NFC/Kipat (optional)
│ (•)) Tap to connect                 └──────┘ │  the one instruction; the mark is the tap cue
└──────────────────────────────────────────────┘
```

Identical on every edition, so any Kipat card is recognisable from the back. The generic inventory
back replaces the name block with the lockup and prints no QR (`back-generic.svg`).

## Critique

- *Risk: circuit-board look.* One line, one turn, no nodes. Never add a second line.
- *Risk: too plain.* The asymmetry and the edge bleed carry it; the raised line adds touch.
- Prints cheaply and reliably; the strongest light design for organisations and professionals.
