# Layered Depth

> **The contact point is the corner of a second plane pressed into the card.**

| | |
|---|---|
| Character | Physical, dimensional, subtle. |
| Tone | Dark |
| Material | Soft-touch laminated white-core PVC with a charcoal flood (fallback: matte). |
| Finish | Choose one with the vendor sample: a 0.15 mm deboss of the plane **or** spot gloss on the plane (both clipped to the safe zone, 25% of the face). |
| Inks | Charcoal flood, plane tone, soft white, cobalt-on-dark. |
| Production complexity | MEDIUM (spot gloss) to HIGH (deboss on PVC: die, vendor capability, chip clearance). |
| Reveal pairing | Spatial Card (recommended, not locked). |

## Front wireframe (before art)

```
┌──────────────────────────────────────────────┐
│ (•)) kipat                                   │  lockup
│                                              │
│                                    ●─────────│  contact point = the plane's square corner
│                                    │░░░░░░░░░│  plane: a half-scale card (W/2 × H/2),
│                                    │░░░░░░░░░│  bleeding off the right and bottom edges
└────────────────────────────────────┴─────────┘
```

| Element | Why it exists |
|---|---|
| Plane, exactly half the card | The single idea: a second card-shaped layer, the physical echo of the Spatial Card Reveal. Half-scale keeps the proportion family exact. |
| Square corner on the contact point | Depth starts where you touch; the only sharp corner on the card. |
| Tonal step, not a gradient | Depth comes from the real finish (deboss or gloss). Printing fake shading would be AI-style fake 3D. |
| Lockup | Same position. |

Nothing else is on the front.

## Back (shared Kipat architecture)

```
┌──────────────────────────────────────────────┐
│ Vash Puno                                    │  name: who this card belongs to
│ BS Computer Science                          │  context: why you'd remember them
│ Polytechnic University of the Philippines    │
│                                     ┌──────┐ │
│                                     │  QR  │ │  fallback for phones without NFC/Kipat (optional)
│ (•)) Tap to connect                 └──────┘ │  the one instruction; the mark is the tap cue
└──────────────────────────────────────────────┘
```

Identical on every edition, so any Kipat card is recognisable from the back. The generic inventory
back replaces the name block with the lockup and prints no QR (`back-generic.svg`).

## Critique

- *Risk: reads as a UI block or a misprint.* The square corner landing exactly on the point is what makes it intentional; never round it.
- *Risk: the flat print is quiet* (1.33:1 tonal step). It depends more on the finish than the others. That is acceptable for the dark signature tier, but it is the weakest flat proof.
- Deboss must avoid the chip module: confirm the inlay drawing first.
