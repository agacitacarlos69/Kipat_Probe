# Card references (Higgsfield)

Reference images for the physical card, generated only **after** the vector artwork existed.
Read [critique.md](critique.md) first.

- `prompts/`: the exact prompts used (one file per job)
- `references/inputs/`: the flat proofs supplied as image references (cropped from the `build.py` proofs)
- `references/`: round-1 product stills, one per finalist (downscaled JPG)
- `photoshoots/`: round-2 finalist images: Graphite Precision front+back hero, Frosted Contact tap moment

**Not production.** Nothing here is source artwork; production geometry lives in `../directions/*/front.svg`
and `back.svg`. Never copy a generated image into `directions/` or `production/`.
